# Changelog

Формат — по релизам пакетов. Версии пакета для OpenWrt и панели LuCI (1.0) и
версия встроенного ядра CSQTT (2.1.9) разделены.

## [1.0.0] — Первый официальный выпуск редакции star-panel-csqtt

Официальный выпуск редакции **star-panel-csqtt**: пакет интеграции для OpenWrt
`csqtt` 1.0, панель `luci-app-csqtt` 1.0 и встроенное ядро CSQTT **2.1.9**.
Ядро — оригинальный CSQTT; редакция добавляет интеграцию в OpenWrt и панель LuCI.

### Возможности

- Профильный пул: автопереключение при сбое (failover), возврат (failback),
  приоритеты, cooldown и повторные подключения.
- Health-контроль (`transport` / `data` / `both`), пороги и интервал проверки.
- Авторизация VK: `vkcalls` (VK-хеши и ссылки `vk.com/call/join`) и `auto_js`
  (по VK access-токену — хеши не нужны).
- Воркеры `9..126` (кратно 9), обфускация `audio` / `video`, TURN `udp` / `tcp_tls`.
- CAPTCHA: встроенный решатель и локальный Web Helper (страница для телефона в LAN).
- LuCI: Status / Profiles / Settings / Logs / CAPTCHA / About, русский перевод.
- Изоляция (interface-only): поднимается только TUN `csqtt0`; маршруты, системный
  DNS, firewall и NAT не изменяются. Трафик направляет пользовательский прокси
  (`interface-name: csqtt0`).
- Секреты (`password`, `vk_js_token`) — write-only: в интерфейс, статус и логи не
  выводятся; пустое секретное поле сохраняет прежнее значение.

### Интерфейс

- **Status** различает три независимых признака: служба запущена, соединение
  установлено, передача данных подтверждена (счётчики RX/TX больше нуля).
- **Profiles** — компактные карточки вместо широкой таблицы: имя, отметка
  активного профиля, фактическое состояние соединения, переключатель с явной
  подписью «Включён»/«Выключен», адрес сервера и приоритет с кнопками изменения.
  Действия — отдельной строкой («Подключить» — главное, «Изменить» и «Экспорт»,
  «Удалить» — визуально отделено и с подтверждением). Дополнительные поля
  (ID, воркеры, TURN/OBFS, CAPTCHA, заметка) — в раскрываемом блоке. Интерфейс
  работает с длинными именами и адресами, списками из 10–20 профилей и без
  горизонтальной прокрутки.
- **Settings** — категории с меню слева (на узком экране — выбор над формой),
  единая панель с заголовком и коротким пояснением, подписи над полями,
  переключатели для булевых настроек, зависимые поля по выбранному режиму.
  Несохранённые значения сохраняются при переходах между категориями; панель
  сохранения не перекрывает содержимое и отражает состояния: несохранённые
  изменения, сохранение, изменения сохранены, ошибка.
- Кнопка диагностики названа понятно для пользователя (без технического `test_conf`).
- Тёмная и светлая темы, видимый фокус и управление с клавиатуры.

### Поле VK-токена

- Принимает и сам access-токен, и **полный OAuth redirect-URL** implicit flow:
  параметр `access_token`/`token` извлекается и URL-декодируется, пробелы по краям
  убираются — и в LuCI, и в ядре (для конфигураций без LuCI).
- Произвольный текст, не являющийся токеном, не превращается в «токен»: LuCI
  сообщает об ошибке, ядро не отправляет его на сервер.
- Ошибка `API 5` объясняется как отказ авторизации с перечнем возможных причин,
  без вывода токена или URL в логи.

### Установка и обновление

- Автоматический установщик обновляет индекс пакетов, проверяет обязательные
  зависимости и завершается с понятной ошибкой, если обязательный шаг не выполнен.
- `apk` корректно выполняет смену схемы версий (в т. ч. понижение номера пакета)
  с сохранением `/etc/config/csqtt`; установщик добавляет откат.

### Известные ограничения

- Поддерживается только `aarch64_cortex-a53` и OpenWrt 25.12.x (`apk`).
- Только interface-only: без пользовательского прокси на `csqtt0` весь трафик
  остаётся вне туннеля.
- `auto_js` требует действующего VK-токена с доступом к звонкам.
- Пакеты не подписаны ключом репозитория OpenWrt — установка с `--allow-untrusted`.
